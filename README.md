# Meridian

Live global market terminal.

## Host on Vercel (free, no Grok plan)

Unzip this archive. You should see `package.json` and `build.mjs` in the **same folder**.

1. Create a new GitHub repository (do not add a README).
2. Upload **all files from this unzipped folder** into the repo root.
   `package.json` must sit at the top of the repo, not inside another `meridian` folder.
3. On Vercel: Add New → Project → import that repo.
4. Root Directory: leave **empty**.
5. Deploy.

If a previous deploy failed, delete the Vercel project and import again with this zip.
